# AI 实用故事素材库

仅由维护者填写，允许本人经历和网络素材两类卡片；写手只读，不得补造经历、数字、对话。

网络素材不能写成董事长本人经历；用“我看到…”“有人分享…”“官方刚上线…”等说法；数字只能引用原文；不搬运原文段落，用自己的话讲做法和看法；正文不放外链。

网络素材限别人公开分享的 AI 实用案例、官方发布的新功能用法、可复现的教程。至少有3张字段齐全且未写过的故事卡才报选题；不足时记录“素材不足”并停止。编号唯一且固定，已有故事不要换编号重复加入。

每张卡用三级标题“编号 + 简短名称”（编号为 S 加数字），本人经历随后逐行填写以下字段；字段值不能为空，“待填”不算素材。无数字就描述可核验结果，无踩坑可填“无”。证据写原始记录或文件位置；隐私资料仅留私有工作区，不提交公开仓库。

| 字段 | 格式说明 |
|---|---|
| 编号 | 三级标题，例如 `### S1 简短名称`；这是格式示意，不是故事 |
| 发生时间 | `- 发生时间：真实日期或时间范围` |
| 麻烦 | `- 麻烦：实际遇到的问题` |
| 让 AI 怎么做 | `- 让 AI 怎么做：本人实际操作与步骤` |
| 结果/数字 | `- 结果/数字：真实结果及数字口径，没有数字不要编` |
| 踩坑 | `- 踩坑：真实失败、限制或吐槽，没有则填无` |
| 可用证据 | `- 可用证据：原始记录、截图或文件位置` |

网络素材使用同样的 S 编号和三级标题，逐行填写以下必填字段；来源链接及证据只存卡片，不进入发布正文。原文没有数字时填写“原文未提供数字”，不要推算。

| 字段 | 格式说明 |
|---|---|
| 来源类型 | `- 来源类型：网络` |
| 来源链接 | `- 来源链接：https://原始公开来源` |
| 原作者/平台 | `- 原作者/平台：原作者及发布平台` |
| 发布日期 | `- 发布日期：原文发布日期` |
| 核心做法 | `- 核心做法：原文可复现的操作步骤` |
| 结果/数字 | `- 结果/数字：只写原文给出的结果及数字` |
| 可借鉴点 | `- 可借鉴点：可以采用的做法及限制` |
| 证据 | `- 证据：原始来源链接即可` |

引用网络素材卡时，程序拒绝正文中的“我用了X天”“我试了”“我做了”等第一人称亲历表述。
