# AI 实用故事素材库

仅由维护者填写董事长真实发生过的事；写手只读，不得补造经历、数字、对话。至少有3张字段齐全且未写过的故事卡才报选题；不足时记录“素材不足”并停止。编号唯一且固定，已有故事不要换编号重复加入。

每张卡用三级标题“编号 + 简短名称”（编号为 S 加数字），随后逐行填写以下字段；字段值不能为空，“待填”不算素材。无数字就描述可核验结果，无踩坑可填“无”。证据写原始记录或文件位置；隐私资料仅留私有工作区，不提交公开仓库。

| 字段 | 格式说明 |
|---|---|
| 编号 | 三级标题，例如 `### S1 简短名称`；这是格式示意，不是故事 |
| 发生时间 | `- 发生时间：真实日期或时间范围` |
| 麻烦 | `- 麻烦：实际遇到的问题` |
| 让 AI 怎么做 | `- 让 AI 怎么做：本人实际操作与步骤` |
| 结果/数字 | `- 结果/数字：真实结果及数字口径，没有数字不要编` |
| 踩坑 | `- 踩坑：真实失败、限制或吐槽，没有则填无` |
| 可用证据 | `- 可用证据：原始记录、截图或文件位置` |
