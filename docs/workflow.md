# 内容流水线

私有配置启用 `pipelineMode: true`，时间均为北京时间；旧经营代码保留，关闭开关可恢复原调度。内核不变。

- 今朝：工作日09:30起，每天最多写一篇。Sonnet自行从手册和故事库选题，读取口吻样本、范文和对比素材，逐篇对照最近10篇已发（含手动帖）。程序检查黑名单、字数、故事引用和对比图；不合格最多重写两次，仍不过当天放弃并记录。
- 今朝程序检查通过，直接发董事长发布确认卡；点发布后固定程序发布、只读回查。退回附意见只修改一次，再发新版确认卡；再次退回作废。
- rabbitrun：每天最多一篇，写稿后程序检查格式、重复与合规红线，通过即固定发布、回读，再发X待发卡；X仍由董事长手动发布。保留在途稿，优先处理，不额外开题。
- 共用账号日限额、未知发布防重、看门狗、数据采集和只读查询保留。发布不明只查结果，不自动重发。
- 每天20:30程序按固定模板发日报：写稿、发布链接、程序退回、待确认、X待发和异常。不调用模型；首次采集的手动帖与真实发帖日期分开说明。
- 停用CEO全部经营轮次、选题会/选题卡、周目标、周五复盘/周报、笔记自动整理、巡检唤醒及额外提醒；异常记维护清单。记住保持暂停，不再向董事长提问或发卡。

上线时关闭旧问题与作废稿件，今朝从配置的下一工作日开始。确认卡和回执继续走既有接口，等待回答不占模型轮次。
